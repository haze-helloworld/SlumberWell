About SlumberWell

Phase 1 — ML Experimentation Summary

Project Overview

SlumberWell is an automatic sleep-stage classifier trained on the Sleep Cassette dataset from PhysioNet. A single EEG channel (Fpz-Cz) is used to extract 16 features per 30-second epoch, classified into five AASM sleep stages:

Phase 1 evaluated five classical ML models with hyperparameter tuning on a leave-one-subject-out split.
